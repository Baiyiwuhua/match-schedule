# 单循环赛程生成器

系篮球赛、羽毛球赛这类单循环赛事的赛程排布工具。给定队伍名单，自动生成每一轮的对阵表；队伍数为奇数时自动安排轮空。

## 目的

组织系篮球赛时，12 支队伍的单循环赛程一直靠手工排：容易漏场、轮次算错、还要反复核对每支队是不是都碰过面。于是写了这个脚本，输入队伍名单，直接输出赛程表和 CSV。

## 运行

```bash
python schedule.py
```

自定义队伍：

```bash
python schedule.py 软件2501 软件2502 网络2501 网络2502 大数据2501
```

## 输出示例（5 支队伍）

```
参赛队伍（5 支）：软件2501、软件2502、网络2501、网络2502、大数据2501

第 1 轮
  ----------------------------------
  软件2501     vs  软件2502
  网络2501     轮空
  网络2502     vs  大数据2501
...
共 5 轮，10 场比赛。
已导出：赛程表.csv
```

## 实现要点

- **轮转法**：固定一支队伍，其余队伍每轮顺时针轮转一位，保证任意两队只碰一次。
- **奇数队**：补一个「轮空」占位，每轮恰好一支队伍轮空。
- **总场次校验**：n 支队伍单循环共 n(n-1)/2 场，脚本结尾会打印总场次，便于核对。
